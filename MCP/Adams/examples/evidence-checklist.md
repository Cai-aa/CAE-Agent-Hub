# Adams evidence checklist

- [ ] Installation, release, workspace and license-dependent execution checked.
- [ ] Requested units, mass, inertia, axes and drive law recorded.
- [ ] Project manifest and generated CMD correspond to the intended mechanism.
- [ ] Constraints and DOF reviewed; redundant constraints investigated.
- [ ] Original input preserved; new runs use separate directories.
- [ ] Batch exit code, timeout state and fatal log signals inspected.
- [ ] Model verification and native simulation invocation present.
- [ ] Numeric reaction/displacement export exists; finite samples, units and full time interval checked.
- [ ] validation.json, hashes.json and report saved.
- [ ] Process completion distinguished from a validated dynamics result.
- [ ] Unsupported live/postprocessing features reported accurately.
- [ ] Public package excludes private settings, logs, results, vendor source and binaries.
