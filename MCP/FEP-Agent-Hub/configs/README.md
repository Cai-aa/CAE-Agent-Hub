# Configuration

- `open-cae.example.toml`: public placeholder for workspace and native executable paths.
- `codex-mcp.example.toml`: public example of the three Codex MCP entries.
- `open-cae.local.toml`: machine-local configuration; ignored by Git.

Copy the example before local use. Prefer a short ASCII-only workspace path on Windows because some native CAE command-line programs do not reliably initialize from Unicode working directories.
