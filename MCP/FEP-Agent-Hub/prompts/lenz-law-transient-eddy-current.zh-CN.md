# FEP Agent Hub：楞次定律瞬态涡流耦合电磁场仿真提示词

你是负责 FEP Agent Hub 的高级 CAE 自动化、瞬态电磁学、有限元验证与 MCP 工程师。请在严格保留现有稳态/瞬态热传导、二维谐波电磁、二维结构和二维层流能力的前提下，新增并使用 FreeCAD、Elmer FEM、ParaView 三个独立 MCP Server，完成一个“变化激励磁场在导体中产生涡流，涡流磁场反抗原磁通变化”的楞次定律瞬态耦合电磁场冒烟案例。

## 一、不可违反的执行原则

1. 必须通过 FEP Agent Hub 的 FreeCAD MCP、Elmer MCP、ParaView MCP 依次完成正式建模、求解和后处理；不得把手写 CSV、伪造 VTU、仅文件存在或媒体动效当作求解成功。
2. 仅允许新增白名单结构化 profile，例如 `magnetodynamics_2d_transient_eddy_v1`；禁止暴露任意 shell、任意 Python、`eval`、任意可执行文件、任意 MATC 表达式或原始 SIF 输入接口。
3. 所有几何长度必须在清单中标注 mm，并在 Gmsh/Elmer 网格中严格转换为 m；求解材料参数全部使用 SI 单位。
4. 每次求解必须同时检查进程退出码、`Elmer Solver: ALL DONE`、错误关键字、预期时间步文件、字段有限性和本提示词定义的物理门禁。
5. 不能验证的能力必须返回 `BLOCKED` 并说明下一步；不得降级为无导电项的静磁场或把谐波相位动画冒充真实瞬态涡流。

## 二、案例目标与物理边界

建立二维平面瞬态磁动力学模型：空气域中央放置一个高电导率闭合导体环或等效导体截面；外侧设置正负成对激励线圈截面。线圈电流使用由结构化参数生成的、分段线性变化的时域波形：先从 0 上升到正峰值，再下降并反向。变化的激励磁通在导体内产生涡流；涡流产生的次级磁场应反抗激励磁通的变化。

模型用于验证楞次定律、瞬态扩散和三软件 MCP 协作，不代表完整工业感应加热器、发电机或三维线圈端部设计。默认采用线性各向同性材料，不包含磁饱和、磁滞、运动网格、热耦合、温升依赖电阻率、辐射或结构力学。

## 三、建议几何和材料参数

- 空气域：160 mm × 120 mm。
- 导体板/闭合导体区域：中央 40 mm × 30 mm；建议使用铜，电导率 `5.8e7 S/m`、相对磁导率 1。
- 激励线圈正/负截面：导体左右两侧各一个 8 mm × 40 mm 矩形，语义分别为 `coil_pos`、`coil_neg`。
- 空气、导体、正线圈、负线圈必须是不重叠、共节点的二维 Physical Surfaces。
- 外边界语义：`outer_boundary`；磁矢势固定为 0。
- 等效模型深度：20 mm，仅用于积分电流/功率等二维到三维的量纲换算。

若上述尺寸导致本机求解器难以稳定收敛，可在保持拓扑和物理目标不变的前提下调整网格尺寸、波形幅值和总时间，并在报告中给出调整前后原因。

## 四、时间波形与求解设置

- profile：`magnetodynamics_2d_transient_eddy_v1`。
- 时间积分：BDF1 或求解器确认支持的稳定隐式格式。
- 基准总时间：20 ms；时间步 `0.5 ms`，共 40 个真实时间步。
- 结构化线圈电流密度波形：
  - `0–5 ms`：从 0 线性上升到 `+Jpeak`；
  - `5–10 ms`：从 `+Jpeak` 线性下降到 0；
  - `10–15 ms`：从 0 线性下降到 `−Jpeak`；
  - `15–20 ms`：从 `−Jpeak` 线性回到 0。
- `coil_pos` 与 `coil_neg` 的电流密度必须等幅反向。
- 波形只能由固定生成器根据数值参数构造，不接受用户输入表达式。
- 导体中不得施加源电流；导体电流必须由时变磁场自然感应得到。
- 每个时间步输出真实 VTU，并建立 PVD 时间集合。

## 五、MCP 调用顺序

1. 环境、工具、资源和模板清单。
2. FreeCAD MCP：创建二维 Face 分区，完成布尔切割/融合、对象检查、几何有效性检查、FCStd、STEP 和 `geometry_manifest.json`。
3. Elmer MCP：创建 transient-eddy case、导入 STEP/manifest、Gmsh 共节点二维物理分区、ElmerGrid 转换、SI 坐标与 semantic map 检查。
4. Elmer MCP：设置空气/铜/线圈材料、瞬态方程、结构化时域激励和外边界，生成/校验 SIF。
5. Elmer MCP：运行真实 ElmerSolver，检查 job/log/VTU/PVD/时间步数量和字段。
6. ParaView MCP：打开 PVD，检查时间值和实际数组，显示磁感应强度、感应电流密度和必要的矢量/流线，导出逐时间步 PNG、CSV、PVSM。
7. 以基准工况、半时间步工况和加密网格工况复算，汇总时间步与网格敏感性。

## 六、必须实现的物理验收门禁

1. `40/40`（或报告中调整后的精确数量）真实时间步文件存在、有限、时间单调且与设置一致。
2. 铜导体内感应电流密度有限、非零；空气区域不得出现与铜同量级的导电电流。
3. 感应电流强度应与激励磁通变化率相关：在电流斜坡段显著，在波形转折/平坦附近按瞬态扩散规律衰减。
4. 楞次定律符号门禁：铜导体存在磁扩散记忆，必须将每个线性斜坡起点的残余总感应磁矩作为基线，从总场中分离该斜坡的增量响应 `Δm_induced=m(t)-m(t_ramp_start)`；四个斜坡中点均须满足 `Δm_induced × dm_external/dt < 0`。同时必须单独报告总感应磁矩完成反号的延迟，不能用增量门禁掩盖总量滞后。
5. 反向波形的对应半周期中，感应电流方向应反转；不能只比较绝对值。
6. 铜区域的焦耳功率密度应为非负，且时间积分能量有限、非零。
7. 半时间步与基准时间步的峰值感应电流/积分能量差异建议 ≤8%；加密网格与基准网格的关键量差异建议 ≤10%。
8. 若使用总场求解，必须在报告中说明如何从总场中分离/定义激励贡献与感应响应，不得凭云图颜色主观宣称“反抗”。

## 七、结果输出

- 逐时间步 `B` 场和导体感应电流密度 `Jeddy` 云图。
- 至少一个带方向箭头的感应电流矢量/等效方向图。
- 时间历程 CSV：激励电流、代表性磁通、`dΦ/dt`、导体积分感应电流或磁矩代理量、峰值/均方根 `Jeddy`、焦耳功率。
- 楞次定律相位/符号关系图，并明确标注上升和下降斜坡。
- 1920×1080、30 FPS、无声音动态视频；视频必须标注“真实瞬态求解”，不能把后期粒子动画当作电流解。
- 中文验证报告：模型假设、三软件调用逻辑、材料/网格/时间步、字段定义、楞次门禁、敏感性、误差、稳定性、能力边界和完整证据路径。

## 八、综合视频接续要求

将本案例接在既有 FEP 综合研究视频中，保留作者“麦克尼克欧”及头像角标。新增段落应展示：激励波形 → 磁通变化 → 铜中感应电流方向 → 楞次符号门禁 → 全部 PASS。片尾保留完整误差表和独立结束页，全片无声音。若总时长超过 45 秒，应以可读性为优先合理延长，不得压缩到看不清物理过程。

最终报告必须区分：真实瞬态求解时间步、ParaView 插值、媒体转场和后期标注。只有来自 Elmer 求解结果并通过字段/物理门禁的数据，才能作为楞次定律验证证据。
