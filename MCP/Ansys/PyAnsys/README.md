# PyAnsys MCP projects / PyAnsys MCP 项目集合

本目录汇总了 Ansys GitHub 组织中名称或描述明确包含 MCP 的官方公开项目。每个子目录都是对应上游仓库 `main` 分支在 2026-08-22 的源码快照；为便于纳入 CAE-Agent-Hub，未保留嵌套的 `.git` 历史。

This directory collects the official public repositories in the Ansys GitHub organization whose names or descriptions explicitly identify them as MCP projects. Each child directory is a source snapshot of the upstream repository's `main` branch as of 2026-08-22. Nested `.git` history is intentionally excluded so the projects can live inside CAE-Agent-Hub.
